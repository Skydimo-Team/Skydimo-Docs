# 用户手册概览

本手册介绍 `src/` 中高级 UI 当前实现的 Skydimo 用户体验。简易 UI
和浏览器模式的重要差异会在相关位置特别说明。

## 一次常规使用流程

1. 启动 Skydimo，等待 Core 连接指示器变为已连接。
2. 等待插件初始化和首次设备扫描完成。
3. 在**首页**选择已发现的设备。如果设备没有自动出现，请使用
   **扫描设备**。
4. 在侧边栏选择要控制的设备、输出或分段。
5. 选择灯效，然后调整亮度和灯效参数。
6. 如果关闭 UI 后仍需保持灯光运行，请让 Core 继续在系统托盘中运行。

通常，操作成功后设置会立即持久化。LED 布局编辑器是一个明显的例外：
在选择**保存**之前，它会一直保留为草稿。

## 工作区导航

| 区域 | 用途 |
|---|---|
| 标题栏 | 窗口控制；在 Windows 高级桌面版中还可切换到简易 UI |
| 首页 | 已连接设备概览和手动设备扫描 |
| 设备树 | 选择设备、输出和分段；执行电源与关联控制操作 |
| 扩展快捷入口 | 直接访问已启用的扩展页面；快捷入口可以固定或取消固定 |
| 插件 | 插件市场、安装包导入、已安装插件状态和扩展页面 |
| 设置 | 语言、启动与关闭行为、采集质量、快捷键、隐私、更新和支持 |
| Toast 通知 | 启动进度、Core 通知、插件操作、错误和更新状态 |

Skydimo 的内部页面不使用 URL 路由。目前不支持浏览器前进/后退、
指向特定设备的深层链接，也不支持刷新后恢复上次打开的页面。

## 连接和启动状态

**首页**旁边的圆点显示 UI 与 Core 的连接状态，其工具提示中还会显示
本地 WebSocket 地址：

- **已连接** — 正常运行。
- **连接中** — Core 正在启动，或 UI 正在重新连接。
- **未连接** — 无法完成设备和灯光操作。

Core 会在所有后台初始化完成之前公布其 WebSocket 端口。启动 Toast
会分别报告插件初始化、设备发现和扩展启动状态。因此，工作区已经可见
并不总是意味着所有灯效或扩展都已准备就绪。

## 设备控制层级

控制层级如下：

```text
设备 → 输出 → 分段
```

侧边栏会压缩简单路径：

- 单输出设备通常会隐藏“输出”节点。
- 只有一个输出包含多个分段时，才会显示分段节点。
- 详情页始终会将所选项目解析为最合适的后端 Scope。

有关继承、关联控制、屏幕/音频源和 LED 锁定的信息，请参阅
[设备与灯效](device-control)。
