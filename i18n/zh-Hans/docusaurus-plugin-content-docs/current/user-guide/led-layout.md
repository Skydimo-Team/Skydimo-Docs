# LED 布局

完整布局编辑器属于高级桌面版工作流程。只有控制器报告了可编辑布局能力的
输出才能使用该编辑器。

## 打开编辑器

打开设备，然后从详情标题区或上下文菜单中选择 LED 编辑操作。对话框会列出
每个可编辑输出及其有序分段。

在选择**保存**之前，所有更改都会保持为草稿。关闭对话框会丢弃草稿。

## 分段类型

| 类型 | 用途 |
|---|---|
| 点 | 添加一个可独立寻址的 LED |
| 线性 | 添加一条具有指定 LED 数量的有序灯带 |
| 矩阵 | 在二维映射中放置 LED |
| 预设 | 重用已保存的产品/布局定义 |

对于线性输出，物理偏移量由前面各分段的顺序和 LED 数量推导。因此，
重新排序或调整某个分段的大小可能会改变后续分段的映射。

## 矩阵编辑

矩阵编辑器支持：

- 单击或拖动以添加/移除单元格；
- 按住鼠标中键或右键拖动以平移；
- 使用滚轮缩放；
- 按行、按列和蛇形顺序自动填充；
- 反选和清空；
- 撤销和重做；以及
- 适应视图。

选中的单元格会映射到从零开始的物理 LED 索引。空单元格不会映射到硬件。

## 实时硬件预览

添加或编辑分段时，UI 会打开一个临时预览会话，并将颜色发送到相关硬件输出。
编辑器保持活动期间会刷新该会话；如果 UI 消失，会话会自动过期。

预览不会持久化。保存对话框会写入实际布局，并重新启动受影响的渲染状态。

## 验证

保存前，Skydimo 会根据控制器能力检查每个输出：

- LED 总数不得低于 `min_total_leds`；
- LED 总数不得超过 `max_total_leds`；以及
- 控制器还可能公布一组允许的总数。

如果验证失败，请调整或移除分段后再次保存。无法通过 UI 安全绕过控制器的
硬件限制。

## 布局变换

当所选 Scope 支持时：

- **水平翻转**会反转水平或线性布局方向。
- **垂直翻转**会反转矩阵或预设布局的垂直方向。

变换设置与分段的物理 LED 数量分开存储。

## 预设

桌面 UI 可以扫描本地预设库、搜索预设、按设备类型筛选，并按品牌分组结果。
矩阵草稿可以保存为可重用预设，其中包含产品名称、品牌、可选的显示名称/类型
以及可选的图片 URL。

预设目录扫描、保存和打开目录使用 Tauri 命令，普通浏览器模式不支持这些操作。

## 简易 UI

简易 UI 有意不提供完整的分段/矩阵编辑器。对于符合条件的线性输出，
它只能在控制器声明的能力范围内安全调整 LED 数量。
