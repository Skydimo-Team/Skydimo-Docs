# 快速开始

## 首次启动

桌面 UI 启动时，会先尝试连接一个正在运行且兼容的 Core。如果没有，
它会启动随应用提供的 `skydimo-core` 可执行文件，并验证 Core 公布的
WebSocket 端口。

Core 可能仍在后台初始化时，工作区就已经显示。请留意以下阶段的启动消息：

1. Core 连接
2. 插件初始化
3. 设备发现
4. 扩展启动

如果某个阶段完成时带有警告，应用仍可继续使用，并会显示报告的详细信息。

## 隐私选择

首次成功连接后，Skydimo 会询问是否可以发送可选的使用情况和诊断数据。
请选择**允许**或**暂不允许**以继续。之后可在
**设置 → 隐私与数据**中更改此选择。

这些可选数据会与一个使用假名的安装标识符关联。设置页面会显示该诊断 ID，
以便支持人员关联问题。

## 连接设备

1. 通过 USB 连接 RGB 设备，或者确保受支持的网络设备可在本地网络上访问。
2. 等待自动发现。
3. 如有需要，在首页选择**扫描设备**。
4. 选择设备卡片以打开其详情页。

Skydimo 通过控制器驱动发现串口和 HID 候选设备，并通过独立的 mDNS
路径发现受支持的网络设备。只有兼容且已启用的控制器成功验证硬件候选项后，
该候选项才会显示为设备。

## 确认基本控制

在设备详情页中：

1. 选择一个简单灯效。
2. 移动亮度滑块。
3. 使用电源按钮关闭和开启所选 Scope。
4. 确认实时 LED 预览和实际硬件都会响应。

如果某项控制从父 Scope 继承值，UI 可能会要求先创建本地模式选择，
之后才能独立调整亮度。

## 保持灯光运行

关闭桌面窗口时可以使用三种行为：

- **每次询问** — 每次关闭时都显示选择。
- **关闭到托盘** — 退出 UI 进程，但让 Core 及其托盘继续运行。
- **退出应用程序** — 关闭 UI，并请求关闭 Core。

选择**记住我的选择**可保存此行为。之后可在设置中更改。

## 浏览器连接

用于开发或仅浏览器使用时：

1. 启动 Core，并从其标准输出中读取 `CORE_PORT=<port>`。
2. 使用以下参数打开相应的 UI 构建：
   `?ws=ws://127.0.0.1:<port>`。
3. 确认连接指示器显示**已连接**。

WebSocket 只监听 `127.0.0.1`。除非 Core 已经过专门重构，加入身份验证和
适当的安全模型，否则不要将此地址替换为局域网接口地址。
