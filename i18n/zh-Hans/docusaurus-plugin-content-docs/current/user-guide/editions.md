# 版本与运行模式

Skydimo 有两种运行时配置，以及两种承载 UI 的方式。UI 和 Core 的运行配置
必须匹配。

## 高级与简易运行配置

| 功能 | 高级 | 简易 |
|---|---|---|
| 主要体验 | 设备树和详细的逐 Scope 控制 | 统一、低复杂度的设备视图 |
| 运行时配置 | `advanced` | `simple` |
| 用户插件包 | 插件市场/导入和开发插件 | 仅随应用提供的 `simple` 和 `built-in` 插件 |
| LED 布局 | 完整的点、线性、矩阵和预设编辑器 | 为符合条件的线性输出安全编辑 LED 数量 |
| 灯效暂停 | 可用 | 已禁用 |
| 采集采样和音频预处理 | 用户可配置 | 由简易运行配置固定 |
| 状态存储位置 | `profiles/advanced/` | `profiles/simple/` |

身份验证、遥测同意状态、启动器元数据和 Core 控制令牌位于共享应用根目录中。
可变的灯光、设备和插件状态会按运行配置分开存储，因此简易 UI 不会重写
高级设置。

:::note
同一时间只有一个 Core 进程可以占用全局控制套接字。如果另一个运行配置
已经在运行，桌面外壳必须先将其关闭，然后才能启动请求的运行配置。
:::

## 桌面模式

桌面应用使用 Tauri 外壳。它可以：

- 启动或连接 Core，并验证所选运行时配置；
- 注册操作系统启动行为；
- 显示关闭到托盘或退出的操作流程；
- 打开配置/插件目录；
- 通过可视化方式选择自定义屏幕区域；
- 扫描和保存本地 LED 布局预设；
- 托管本地扩展页面；以及
- 打包并提交诊断反馈。

在 Windows 上，高级版标题栏包含**切换到简易 UI**。简易 UI 也有一个
受保护的路径可以切换回高级模式。执行切换时，对应的前端可执行文件必须安装在
当前应用旁边。

## 浏览器模式

浏览器 UI 使用明确指定的 URL 连接到已经运行的 Core：

```text
http://<ui-host>/?ws=ws://127.0.0.1:<core-port>
```

高级浏览器构建会验证 Core 报告的是 `advanced` 配置；简易构建则要求
`simple`。配置不匹配会被视为终止性连接错误。

浏览器模式适用于开发和本地集成，但无法替代桌面系统集成：

- 本地扩展 `page` 文件仅支持桌面版；外部 `page_url` 页面可能可以在
  浏览器中工作；
- 屏幕区域可视化选择、布局预设文件、反馈上传、托盘、自动启动和真实窗口
  关闭行为都需要 Tauri；
- 应用偏好设置存储在浏览器本地存储中；
- 部分面向桌面的控件可能仍会显示，但无法执行相应的操作系统操作。

如需完整的最终用户工作流程，请使用桌面应用。
