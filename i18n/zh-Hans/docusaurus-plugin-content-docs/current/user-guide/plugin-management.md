# 插件管理

从侧边栏打开**插件**。高级模式提供“市场”“灯效”“控制器”和“扩展”
选项卡。

## 插件市场

插件市场默认打开最新列表。按名称或关键字搜索，然后使用：

- **下载并安装**来安装新插件；
- 有较新安装包时使用**更新**；或者
- 在无需操作时查看“已安装”指示。

安装过程会下载安装包、扫描其中的清单，并安装所选插件 ID。当前 UI 只显示
数量有限的最新/搜索结果；分页、“加载更多”控件和独立插件详情页尚未实现。

## 导入安装包

1. 选择**导入插件**。
2. 选择一个 `.skyplugin` 安装包。
3. 等待安装包扫描完成。
4. 选择一个或多个已发现的插件。
5. 选择**安装**。

安装包可以包含灯效、控制器、扩展，或者列出子插件的插件包。简易运行配置
不支持安装。

## 启用或禁用插件

使用“灯效”“控制器”或“扩展”选项卡搜索已安装插件。可以直接切换单个
插件，也可以进入多选模式进行批量启用/禁用。

- 禁用灯效后，新选择中将不再显示该灯效。
- 禁用控制器可能会移除依赖它的设备。
- 禁用扩展会停止其后台运行时、移除其注册的设备、释放其 LED 锁，
  并关闭其资源。

插件变更可能触发设备重新扫描，并重新启动活动的运行器。

## 扩展页面

已启用的扩展可以提供：

- 由桌面应用托管、随插件提供的本地 `page`；或者
- 外部 HTTPS/HTTP `page_url`。

本地页面仅支持桌面版。外部页面可能同时支持桌面和浏览器模式。页面通过同一个
Core WebSocket 连接与其扩展交换数据。

扩展页面快捷入口会显示在侧边栏中，并且可以固定或取消固定。如果当前打开的
扩展被禁用或移除，UI 会返回插件概览。

## 上下文操作

右键单击本地插件可使用以下操作：

- 复制插件 ID；
- 多选；
- 打开插件目录；
- 打开插件数据目录；
- 删除已安装插件；或者
- 恢复随应用提供的版本/默认版本。

**删除**会移除已安装的插件包。存在随应用提供的版本时，**恢复默认**
会移除用户覆盖版本。这两项操作都可以选择同时移除插件数据。开发插件会从
源目录直接加载；如果源目录仍然存在，刷新后它们可能会重新出现。

## 刷新

修改开发插件后，请使用**刷新**。刷新会停止并重新启动扩展、重建插件注册表、
重新扫描硬件，并重新启动活动的设备运行器。短暂的灯光中断属于正常现象。

插件作者请继续阅读
[插件开发概览](../plugins/overview)。
