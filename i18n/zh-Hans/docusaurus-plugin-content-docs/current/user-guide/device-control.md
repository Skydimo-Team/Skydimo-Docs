# 设备与灯效

## 选择 Scope

Skydimo 在三个层级存储和解析灯光状态：

```text
设备 → 输出 → 分段
```

可以在侧边栏选择节点，也可以在 LED 预览中选择区域。侧边栏会隐藏多余的
单输出和单分段层级，但 Core 仍会将操作解析到具体 Scope。

输出或分段可能会从父级继承灯效。UI 会区分本地选择的值与经过继承后实际
生效的值。

## 电源和亮度

电源操作作用于所选 Scope。在父级执行时，操作会递归应用到下层渲染目标；
当所有相关子项都关闭时，父级会显示为关闭。

亮度会随当前模式的继承关系解析：

- 跟随父级的子项会显示父级实际生效的亮度。
- 当 UI 提供**单独设置**时，选择该操作可创建本地模式选择，然后独立调整亮度。
- 拖动滑块时会快速预览；交互结束后才提交最终值。

## 关联控制

使用设备树中的关联控制按钮，可以通过共享根节点和共享灯效时间线控制设备。
当前 UI 将其描述为在设备之间同步灯效切换。部分相关 Core 操作也会使用
共享状态，但操作流程不应假设每一项设备设置都会同步。

如需开启或关闭所有设备，请使用独立的“所有设备电源”操作。

## 选择和配置灯效

灯效会按照 Core 返回的元数据分组。收藏的灯效显示在单独分类中，并作为
应用偏好保存。

设置面板根据所选灯效的元数据生成。支持以下控件：

- 滑块；
- 范围滑块；
- 选择框；
- 开关；
- 颜色；以及
- 多颜色。

参数可以分组，依赖条件可以隐藏或禁用参数。使用**恢复默认参数**可重置
所选 Scope 上的当前灯效。**暂停模式**可以冻结当前灯效而不切换到其他灯效；
简易运行配置不支持暂停。

## 屏幕响应灯效

声明 `screen:capture` 的灯效会提供：

- 显示器选择；
- 全屏、顶部、底部、左侧或右侧采集区域；以及
- 使用物理像素表示的自定义矩形区域。

桌面应用可以通过可视化方式选择自定义区域。浏览器模式可以显示坐标控件，
但无法打开 Tauri 区域选择遮罩层。

全局采样方式、分辨率预算和帧率在设置中配置。在 Windows 上，根据构建和
平台支持情况，可以提供 DXGI、Windows Graphics Capture 和 GDI 等方式。

## 音频响应灯效

声明 `audio:capture` 的灯效会提供音频设备选择和预处理控件。默认输出选项
会跟随操作系统的默认输出设备。

可用的预处理设置包括振幅、平均方式和大小、FFT 窗、衰减、滤波常数、
归一化偏移和归一化缩放。使用**重置**可让所选 Scope 恢复为继承的或默认的
音频处理状态。

## 锁定与冲突保护

扩展可以锁定单个 LED。部分锁定会显示锁定数量和所有者；完全锁定表示该扩展
当前控制 Scope 中的每一个 LED。完全锁定的设备默认会从设备树隐藏，可通过
锁定设备可见性控件重新显示。

当已知的冲突软件正在运行时，Skydimo 也可以暂停控制。安全视图会指出对应
进程，并可能提供故障排除链接。忽略警告会恢复输出，但如果两个应用同时写入
硬件，可能导致闪烁、颜色错误或硬件问题。测试完成后，请重新启用保护。

## 设备工具

设备标题区和上下文菜单可能提供：

- 重命名设备或输出；
- 自动或手动选择控制器；
- 设备专用的控制器设置；
- 在支持时水平/垂直翻转布局；
- 编辑 LED 布局；以及
- 查看身份信息、控制器、输出、冲突和运行时 FPS 信息。

水平翻转适用于线性、矩阵和预设布局。垂直翻转适用于矩阵和预设布局。
