# 设置

从侧边栏右下角的操作入口打开设置。

## 账户

Skydimo 账户卡片会启动基于浏览器的授权，并持续轮询，直到请求成功、失败、
被取消或过期。缓存的登录状态可能显示为离线。可以从同一张卡片退出登录。

## 偏好设置

### 语言

当前 UI 资源包括德语、英语（美国）、西班牙语、法语、俄语、土耳其语、
简体中文和繁体中文。更改区域语言也会更新 Core/插件的本地化文本。

### 随系统启动

桌面模式可以注册 Skydimo，使其在后台随系统启动。自动启动程序会静默启动
或连接 Core，然后退出 UI 外壳。

### 关闭窗口

可以选择**每次询问**、**关闭到托盘**或**退出应用程序**。关闭到托盘会退出
桌面 UI，但让 Core 及其托盘进程继续运行。

浏览器模式可以存储这些偏好设置，但无法注册自动启动或控制桌面窗口。

## 屏幕同步

配置全局采集方式、采样分辨率和帧率。较高设置能提高颜色准确度和运动流畅度，
但会消耗更多 CPU、GPU 和内存带宽。

在 Windows 上，可用的采集方式可能包括：

- **DXGI** — 适合大多数系统的高性能默认方式；
- **Windows Graphics Capture** — 可能显示系统边框的现代采集方式；以及
- **GDI** — 性能较低的兼容性后备方式。

分辨率预设范围从很小的采样预算到原始分辨率。帧率可以在 1 至 60 FPS 之间
配置。简易运行配置会锁定采样分辨率和帧率。

## 全局快捷键

可以配置五项系统级操作：

- 开启所有灯光；
- 关闭所有灯光；
- 切换所有灯光；
- 将所有亮度提高 5%；以及
- 将所有亮度降低 5%。

聚焦快捷键字段，然后按下所需组合键。Delete 可清除录制内容，Escape 可取消。
重复的组合键会被拒绝。

## 隐私与诊断

遥测开关控制可选的假名化使用情况和诊断数据。卡片还会显示诊断安装 ID，
并提供隐私政策链接。

反馈提交仅支持桌面版。它要求填写消息，可选填联系方式，并会打包当前及轮换的
Core/Tauri/webview 日志和部分配置的有限、已清理子集。提交前请查看对话框中
显示的说明。

## 关于、配置与更新

“关于”卡片会显示操作系统、Tauri 和应用版本。它可以打开正在运行的 Core
使用的配置目录。如果外壳和 Core 解析出的目录不同，则会同时显示两个位置。

**检查更新**会查询更新服务。接受更新时，当前实现会打开提供的下载 URL；
它不会在应用内执行二进制文件安装。

## 联系方式

联系卡片会显示受支持的电子邮件/社区渠道和桌面反馈入口。可用性可能因平台而异。
